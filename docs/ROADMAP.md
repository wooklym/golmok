## Phase 1 — MVP (계획안, 승인 후 확정)

목표:
1. 파일럿 지역의 베이스맵 위에서 3인칭 캐릭터가 걷고 뛸 수 있다.
2. 골목 1곳이 고품질로 재구성되어 들어간다.
3. 건물 1곳의 내부에 들어가 돌아다닐 수 있다.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1.0 스파이크(2주) | 공개 샘플 splat 위에서 Rapier 캐릭터를 걷게 한다. Spark 2 vs PlayCanvas를 모바일에서 측정한다 | fps, 메모리, 로딩 수치 표 작성 → D-003 확정 |
| 1.1 저장소 골격 | `apps/client`, `pipeline`, `tools/basemap`, CI(lint, typecheck, Playwright 스모크) | CI green |
| 1.2 베이스맵 빌더 | GIS건물통합정보 + DEM + 정사영상 → 3D Tiles(`building_id` 메타데이터 포함) | 파일럿 지역 타일셋이 브라우저에서 로드된다 |
| 1.3 캐릭터·물리 | floating origin, 3인칭 카메라, 걷기·뛰기·점프, 베이스맵 충돌 | 지역 전체를 돌아다닐 수 있다 |
| 1.4 촬영 ① 골목 | 촬영 가이드 전달 → 네가 촬영 | 원본 업로드 완료 |
| 1.5 파이프라인 v0 | 블러·마스크 → COLMAP → gsplat → collision → 정합 → manifest | 골목 Zone이 생성되고 자동 지표가 임계값을 통과한다 |
| 1.6 Zone 교체 | 베이스맵 건물 숨김, 지면 클리핑, 충돌 스왑, 경계 블렌드 | 골목에서 걸을 때 이음새가 없다 |
| 1.7 촬영 ② 실내 | 소유자 동의서 → 촬영 → Interior Zone + portal | 문으로 들어가 실내를 돌아다닐 수 있다 |
| 1.8 검수·폴리시 | 디버그 뷰, 모바일 성능 튜닝 | 목표 기기 30fps |
