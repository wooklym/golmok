# 촬영 목록 (Zone 백로그)

"가는 곳마다 찍어 올리는" 방식(D-008)의 촬영 기록이다. 원본(사진·영상)은 **저장소에 넣지 않는다.** PC와 외장 디스크에 보관하고, 여기에는 메타데이터만 적는다.

| ID | 날짜 | 지역 | 골목 설명 / 대략 위치 | 길이 | 사진/영상 | 날씨 | §0 체크 | 실내 후보 | 상태 |
|---|---|---|---|---|---|---|---|---|---|
| (예) alley01 | 2026-MM-DD | 연남동 | ○○로 ○길, 교차로 1곳 포함 | 약 100m | 1,320장 / 18분 | 흐림 | OK | ○○카페(동의 미확인) | 원본 보관 |

상태: `원본 보관` → `블러 완료` → `재구성 중` → `Zone 완료` / `보류`(사유 기재)
