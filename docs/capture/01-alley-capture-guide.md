# 촬영 가이드 #1 — 골목 1곳 (Phase 1 스파이크 + MVP 겸용)

버전: v2 (2026-09-24, iPhone 17 Pro 기준으로 개정)
용도: Phase 1 스파이크 1.0의 **(a) RealityScan 메시**, **(b) Cesium splat**, **(c) 서드파티 splat 플러그인** 세 방식을 **같은 데이터로 비교**하기 위한 촬영이다. 이 데이터는 스파이크가 끝난 뒤 MVP 골목 Zone의 원천으로도 그대로 쓴다.

> **원칙: 한 번 찍어 세 방식에 모두 쓴다.**
> - 메시(RealityScan)는 선명한 고해상도 **사진**을 좋아한다.
> - splat(Postshot)은 **플레이어 시점 높이의 연속된 시점**을 좋아한다.
> - 그래서 **사진 패스**와 **영상 패스**를 모두 찍는다.

---

## 0. 촬영 전 30초 체크 (어디서 찍든 매번)

"가는 곳마다 찍어 올리는" 방식이므로, 장소마다 아래를 확인한다. 하나라도 걸리면 **찍지 않거나 방향을 바꾼다.**

- [ ] **보안·경호 시설이 프레임에 들어오지 않는가**
  - 군부대, 정부청사, 경찰·교정시설, 발전소·변전소·정수장 같은 기반시설
  - **대통령 관저**: 한남동 관저는 2026-09 현재 청와대 관저 공사로 **임시 사용 중**이다 [2차]
  - **한남동 공관촌**, **대사관·영사관 정문과 경비초소**
  - 이런 곳은 경비원이 제지하기 전에 먼저 피한다(05 문서 §3).
- [ ] **공도(公道)인가.** 대문 안, 주차장 안, 건물 로비, 아파트 단지 안은 찍지 않는다.
- [ ] **사람이 적은가.** 행인이 많으면 시간대를 바꾼다.
- [ ] **날씨와 빛**: 흐림이 최선이다. 햇빛과 그늘이 섞인 골목은 다음 기회로 미룬다.
- [ ] 브랜드 플래그십이나 팝업이 밀집한 거리(가로수길 본선, 연무장길 본선 등)라면 **이면 골목을 우선**한다. 로고 교체 부담이 크고 매장이 금방 바뀐다.

## 1. 촬영 범위

- **골목 한 구간, 길이 80~120m.**
- 한쪽 끝이나 중간에 **교차로(또는 꺾이는 지점) 1곳을 포함**한다. 루프를 닫아 드리프트를 줄이기 위해서다.
- 구간 안에 **나중에 실내 촬영을 할 건물(동의 가능한 가게)의 입구**가 있으면 가장 좋다. 실내 Zone을 연결하기 쉬워진다.
- 촬영 대상:
  - 양쪽 건물 외벽: 1층은 전부 찍고, 위층은 지상에서 보이는 만큼 찍는다.
  - 바닥: 도로, 보도 턱, 맨홀, 계단.
  - 골목 양 끝의 "출구" 방향 경관.
- 범위 밖이지만 **경계에서 5~10m까지는 더 찍는다.** 베이스맵과 이어 붙일 여유분이다.

## 4. 아이폰 설정

### 4-A. 사진: 기본 카메라 앱
**촬영 전 설정** (설정 → 카메라)
- **포맷 → "ProRAW 및 해상도 제어" 켬 → Pro 기본값: ProRAW Max(48MP)**
- **매크로 제어 켬.** 이렇게 해야 촬영 화면에서 자동 매크로(초광각 자동 전환)를 **끌 수 있다**. 벽에 가까이 가도 렌즈가 바뀌지 않게 하기 위해서다.
- **설정 보존**(Preserve Settings): 크리에이티브 제어, 노출 조정, ProRAW, **매크로 제어**를 모두 켠다. 앱을 다시 열어도 설정이 풀리지 않는다.
- Live Photo 끔. 인물 모드와 야간 모드는 쓰지 않는다. 사진 스타일은 기본(표준)으로 둔다.
- "더 빠른 촬영 우선 처리"는 **끔**(품질 우선).

**촬영할 때**
- **1x 고정**. 줌 버튼을 누르지 않는다. 화면에 매크로(꽃 아이콘)가 뜨면 끈다.
- 촬영 시작 전 중간 밝기의 벽을 **길게 눌러 AE/AF 잠금**을 건다. 노출 보정은 −0.3 정도로 두어 하늘과 흰 벽이 날아가지 않게 한다.
  - 잠금은 다른 곳을 탭하면 풀린다. **스트립마다 다시 잠그고** 그 사실을 메모한다.
- 셔터는 앱이 자동으로 정한다. 그래서 **흐린 날 이른 아침에 셔터가 충분히 빠른지 리허설로 확인**한다(§4-C).

### 4-B. 영상: Blackmagic Camera 앱
| 설정 | 값 |
|---|---|
| 렌즈 | **1x 메인** |
| 해상도·프레임 | **4K, 60fps** |
| 셔터 | **셔터 스피드 표시로 바꾼 뒤 1/250~1/500 고정**(180° 규칙은 무시한다. 영상미보다 프레임 선명도가 중요하다) |
| ISO | 수동. 노출이 맞는 최저값(흐린 아침이면 대략 200~800) |
| 화이트밸런스 | **수동 6000K 전후 고정**(흐림) |
| 초점 | 수동으로 먼 거리 쪽에 고정, 또는 AF 후 잠금 |
| 코덱 | **HEVC(H.265) 10-bit, 고비트레이트.** ProRes는 용량이 매우 크고, 4K 고프레임은 외장 SSD 기록이 필요할 수 있다 [2차] |
| 색 | Rec.709(기본). Apple Log 2는 쓰지 않는다(학습 전 변환 단계가 늘어난다) |
| 손떨림 보정 | 켬(표준) |

### 4-C. 리허설 (첫 촬영 전에 집 근처에서 10분)
1. 흐린 날 비슷한 밝기에서 벽을 걸으며 **사진 20장과 영상 1분**을 찍는다.
2. PC로 옮긴 뒤 사진 EXIF의 **셔터 속도**를 확인한다.
   - Windows 파일 속성 → 자세히에서 볼 수 있다. EXIF를 모아 보여주는 스크립트는 내가 만들어 줄 수 있다.
   - 대부분 **1/200s 이상이면 OK**다.
   - 1/125s보다 느린 컷이 많으면 알려준다. 그 경우 수동 셔터 앱으로 바꾸고 해상도와 선명도를 트레이드오프하는 방안을 다시 정한다.
3. 100% 확대해서 흔들림을 확인한다. 걸으며 찍지 말고 **멈춰서 찍는 습관**을 들인다.

### 4-D. PC로 옮기기 (Windows)
- **아이폰 설정 → 사진 → "Mac 또는 PC로 전송" → "원본 유지"**
  - 이 설정을 하지 않으면 HEIC/ProRAW가 JPEG로 변환되어 품질이 떨어진다.
- USB-C 케이블로 연결해 Windows 사진 앱이나 탐색기(DCIM)로 복사한다. 영상은 Blackmagic 앱의 파일 공유(파일 앱)로 꺼낸다.

## 5. 사진 패스 (메시 + splat 공통, 핵심)

골목 폭을 W(보통 4~8m)라고 한다.

### 패스 P1 — 외벽 스트립 (양쪽 각각)
- **맞은편 벽에 붙어 서서** 촬영할 벽을 정면(수직)으로 겨눈다.
- **옆으로 한 걸음(약 0.6~0.8m)씩 이동하며 한 장씩** 찍는다. 인접 사진 겹침은 **70~80%**가 목표다.
- 한 지점에서 **높이·각도 3단**을 찍는다.
  1. 눈높이, 수평
  2. 눈높이, **아래로 20~30°**(1층 하단·바닥과 벽이 만나는 선)
  3. 셀카봉을 **머리 위로 들고 위로 20~40°**(2~3층, 처마, 간판)
- 골목 끝까지 갔다가 **반대쪽 벽으로 건너가 되돌아온다.**
- 예상 매수: 100m × 2면 ÷ 0.7m × 3단 = **약 850장**

### 패스 P2 — 사선(오블리크) 스트립
- 골목 **중앙선**을 따라 걸으며 좌우 벽을 **진행 방향 기준 약 45°**로 찍는다. 앞쪽 사선과 뒤쪽 사선을 모두 찍는다.
- 1~1.5m마다 4장(좌앞, 우앞, 좌뒤, 우뒤)씩, 눈높이 수평으로 찍는다.
- 예상 매수: **약 250~300장**
- 목적: P1 스트립끼리를 연결하고, 벽의 돌출부·기둥·창틀 측면을 채운다.

### 패스 P3 — 교차로·모서리·끝단 궤도
- 교차로와 꺾이는 모서리에서는 모서리를 중심으로 **반원 궤도**를 그리며 **10~15° 간격**으로 찍는다.
- 골목 양 끝에서는 **들어오는 방향과 나가는 방향**을 각각 찍는다(베이스맵 연결부).
- 예상 매수: **약 100장**

### 패스 P4 — 디테일·바닥·입구
- **실내 촬영 예정 건물의 입구**: 문, 문턱, 창, 간판을 반원 궤도로 찍는다(약 30~40장). 나중에 실내 Zone과 정렬할 때 공통 특징이 된다.
- **바닥**: 중앙선을 따라 약 1m 간격으로 **아래 45°** 촬영(약 100장). 보도 턱, 계단, 배수구가 캐릭터 발 딛는 곳의 품질을 좌우한다.
- 예상 매수: **약 150장**

**사진 합계: 약 1,300~1,400장**

## 6. 영상 패스 (splat 보강용)

- **Blackmagic Camera 앱**, §4-B 설정(4K60, 셔터 1/250~1/500, ISO·WB·초점 고정).
- **아주 천천히**(보통 걸음의 절반) 걷는다. 카메라를 **팬만 하지 말고 반드시 이동하며** 찍는다.
- 궤적(각각 골목 전체를 왕복한다):
  - V1: 가슴 높이(약 1.3m), 진행 방향 정면 → 되돌아올 때도 정면
  - V2: 머리 위 높이(약 2.2~2.5m, 셀카봉), 정면 → 3인칭 카메라 높이에 해당
  - V3: 중앙선에서 좌측 벽을 45°로, 되돌아올 때 우측 벽을 45°로
- 예상 분량: 약 **15~25분**

## 7. 스케일·위치 기준

- 줄자나 레이저로 **식별하기 쉬운 두 점 사이 거리 3곳**을 잰다. 예: 창틀 폭, 대문 폭, 맨홀 지름, 연석 간격.
  - 사진을 찍고 **메모장에 "사진 번호 + 측정값"**을 기록한다.
- 촬영 시작점과 끝점에서 폰 지도 앱의 **현재 위치를 스크린샷**한다.
- 아이폰 사진 EXIF에 GPS가 자동으로 기록된다(카메라 앱 위치 권한 확인). 별도 GPS 로거는 필요 없다.
- 표식을 바닥에 두거나 붙이지 않는다(공공 도로).

## 8. 촬영 예절·법적 주의 (05 문서 요약)

- **사람을 찍으려 하지 않는다.** 행인이 프레임에 들어오면 지나갈 때까지 기다린다. 우연히 찍힌 얼굴과 번호판은 파이프라인에서 블러·제거된다.
- 누가 촬영을 거부하거나 물어보면 **즉시 멈추고** 설명한다. 요청하면 해당 사진을 삭제한다.
- **창문 안쪽(가정집 내부)을 겨냥하지 않는다.** 유리 너머가 보이는 각도는 피한다.
- 사유지(대문 안, 주차장 안, 가게 안)에는 **들어가지 않는다.** 실내는 별도 동의 후 가이드 #2로 찍는다.
- 드론은 쓰지 않는다.
- 이 데이터는 **외부에 공유하지 않는다**(원본에는 얼굴과 번호판이 있다).
