# 촬영 가이드 #1 — 골목 1곳 (Phase 1 스파이크 + MVP 겸용)

버전: v1 (2026-09-24)
용도: Phase 1 스파이크 1.0의 **(a) RealityScan 메시**, **(b) Cesium splat**, **(c) 서드파티 splat 플러그인** 세 방식을 **같은 데이터로 비교**하기 위한 촬영이다. 이 데이터는 스파이크가 끝난 뒤 MVP 골목 Zone의 원천으로도 그대로 쓴다.

> **원칙: 한 번 찍어 세 방식에 모두 쓴다.**
> - 메시(RealityScan)는 선명한 고해상도 **사진**을 좋아한다.
> - splat(Postshot)은 **플레이어 시점 높이의 연속된 시점**을 좋아한다.
> - 그래서 **사진 패스**와 **영상 패스**를 모두 찍는다.

---

## 1. 촬영 범위

- **골목 한 구간, 길이 80~120m.**
- 한쪽 끝이나 중간에 **교차로(또는 꺾이는 지점) 1곳을 포함**한다. 루프를 닫아 드리프트를 줄이기 위해서다.
- 구간 안에 **나중에 실내 촬영을 할 건물(동의 가능한 가게)의 입구**가 있으면 가장 좋다. 실내 Zone을 연결하기 쉬워진다.
- 촬영 대상:
  - 양쪽 건물 외벽: 1층은 전부 찍고, 위층은 지상에서 보이는 만큼 찍는다.
  - 바닥: 도로, 보도 턱, 맨홀, 계단.
  - 골목 양 끝의 "출구" 방향 경관.
- 범위 밖이지만 **경계에서 5~10m까지는 더 찍는다.** 베이스맵과 이어 붙일 여유분이다.

## 2. 날짜·시간·날씨 (퀄리티에 가장 큰 영향)

| 항목 | 권장 | 이유 |
|---|---|---|
| **날씨** | **균일한 흐린 날**(구름이 두껍고 그림자가 거의 없는 날) | 텍스처에 그림자가 구워지면 Lumen 동적 조명·그림자와 충돌한다. 퀄리티 최우선 기준에서 **가장 중요한 조건**이다. |
| 차선 | 맑은 날이라면 해가 건물에 가려 골목 전체가 그늘인 시간대 | 햇빛과 그늘이 섞이면 가장 나쁘다. |
| 요일·시간 | **평일 이른 아침(06:30~08:30)**, 가게 문 열기 전 | 사람, 차량 이동, 셔터 개폐가 가장 적다. 지역별 세부 사항은 §9 참고. |
| 피할 것 | 비 온 직후(젖은 바닥 반사), 강풍(나뭇잎·현수막 흔들림), 해질녘(빛이 빠르게 변함) | |
| 소요 시간 | 사진 패스 약 60~90분 + 영상 패스 약 20~30분 | **빛이 크게 바뀌기 전에 끝낸다.** 두 번에 나눠 찍을 거라면 같은 날씨·시간대로 맞춘다. |

## 3. 장비

**우선순위 순**이다. 가진 장비를 알려주면 설정을 맞춰준다.

| 장비 | 권장 | 비고 |
|---|---|---|
| **카메라 A (최선)** | 미러리스나 DSLR, 풀프레임 또는 APS-C, 2,400만 화소 이상 | 초점거리는 **24mm 전후**(풀프레임 환산), 단렌즈나 줌을 24mm에 고정한다. |
| 카메라 B (대안) | 최신 스마트폰 메인 카메라(1x) | **초광각(0.5x)은 쓰지 않는다**(왜곡, 해상도). 가능하면 **Pro/수동 모드 + RAW(DNG) 또는 ProRAW**. |
| 영상 | 카메라 A나 B 중 **4K 촬영이 되는 쪽** | §6 영상 패스용 |
| 짐벌/셀카봉 | 1~2m 연장되는 모노포드나 셀카봉 | 위층을 찍는 "높은 링"에 쓴다. 블루투스 셔터나 인터벌 촬영을 함께 쓴다. |
| 줄자 또는 레이저 거리계 | 필수 | 스케일 기준(§7) |
| 여분 배터리와 메모리 | 사진 약 1,200장 + 4K 영상 30분 이상 | RAW+JPG 기준으로 약 60~100GB |
| 스마트폰 GPS | 카메라 GPS가 없으면 폰으로 **GPS 로거 앱** 기록 | 시계를 카메라와 맞춘다. 사진 EXIF와 대조하는 데 쓴다. |

## 4. 카메라 설정

| 설정 | 값 | 이유 |
|---|---|---|
| 모드 | **수동(M)** | 노출이 사진마다 바뀌면 텍스처 이음새가 생긴다. |
| 노출 | 촬영 시작 때 한 번 맞추고 **고정**. 크게 어두워지는 구간에서만 다시 맞추고 메모한다. | |
| 셔터 | **1/250s 이상**(걸으면서 찍을 때는 1/500s) | 모션 블러는 재구성의 최대 적이다. |
| 조리개 | f/5.6~f/8 | 피사계 심도 확보 |
| ISO | 셔터와 조리개를 맞춘 뒤 필요한 만큼 올린다(카메라 A는 3200까지 허용) | **블러보다 노이즈가 낫다.** |
| 초점 | AF-S 단일, 중앙 1점. 또는 과초점 거리 **MF 고정** | 사진마다 초점이 튀지 않게 한다. |
| 화이트밸런스 | **수동 고정**(흐린 날 약 6000K 또는 "흐림" 프리셋) | AWB는 사진마다 색이 달라진다. |
| 포맷 | **RAW + JPG** | RAW는 원본 보관용, 후처리 때 노출을 통일하는 데 쓴다. |
| 손떨림 보정 | 켬 (단, 삼각대 사용 시 끔) | |
| 줌 | **고정(24mm 전후), 촬영 내내 바꾸지 않음** | 초점거리가 바뀌면 캘리브레이션 그룹이 늘어난다. |
| 스마트폰 | 1x 렌즈 고정, HDR·인물모드·야간모드 **끔**, 노출 잠금(AE/AF Lock) | |

## 5. 사진 패스 (메시 + splat 공통, 핵심)

골목 폭을 W(보통 4~8m)라고 한다.

### 패스 P1 — 외벽 스트립 (양쪽 각각)
- **맞은편 벽에 붙어 서서** 촬영할 벽을 정면(수직)으로 겨눈다.
- **옆으로 한 걸음(약 0.6~0.8m)씩 이동하며 한 장씩** 찍는다. 인접 사진 겹침은 **70~80%**가 목표다.
- 한 지점에서 **높이·각도 3단**을 찍는다.
  1. 눈높이, 수평
  2. 눈높이, **아래로 20~30°**(1층 하단·바닥과 벽이 만나는 선)
  3. 셀카봉을 **머리 위로 들고 위로 20~40°**(2~3층, 처마, 간판)
- 골목 끝까지 갔다가 **반대쪽 벽으로 건너가 되돌아온다.**
- 예상 매수: 100m × 2면 ÷ 0.7m × 3단 = **약 850장**

### 패스 P2 — 사선(오블리크) 스트립
- 골목 **중앙선**을 따라 걸으며 좌우 벽을 **진행 방향 기준 약 45°**로 찍는다. 앞쪽 사선과 뒤쪽 사선을 모두 찍는다.
- 1~1.5m마다 4장(좌앞, 우앞, 좌뒤, 우뒤)씩, 눈높이 수평으로 찍는다.
- 예상 매수: **약 250~300장**
- 목적: P1 스트립끼리를 연결하고, 벽의 돌출부·기둥·창틀 측면을 채운다.

### 패스 P3 — 교차로·모서리·끝단 궤도
- 교차로와 꺾이는 모서리에서는 모서리를 중심으로 **반원 궤도**를 그리며 **10~15° 간격**으로 찍는다.
- 골목 양 끝에서는 **들어오는 방향과 나가는 방향**을 각각 찍는다(베이스맵 연결부).
- 예상 매수: **약 100장**

### 패스 P4 — 디테일·바닥·입구
- **실내 촬영 예정 건물의 입구**: 문, 문턱, 창, 간판을 반원 궤도로 찍는다(약 30~40장). 나중에 실내 Zone과 정렬할 때 공통 특징이 된다.
- **바닥**: 중앙선을 따라 약 1m 간격으로 **아래 45°** 촬영(약 100장). 보도 턱, 계단, 배수구가 캐릭터 발 딛는 곳의 품질을 좌우한다.
- 예상 매수: **약 150장**

**사진 합계: 약 1,300~1,400장**

## 6. 영상 패스 (splat 보강용)

- 4K, **60fps 권장**(가능하면 셔터 1/250s 이상 수동 고정). 안 되면 30fps.
- 수동 노출과 WB를 고정하고, 손떨림 보정은 **켠다**(짐벌이 있으면 짐벌).
- **아주 천천히**(보통 걸음의 절반) 걷는다. 카메라를 **팬만 하지 말고 반드시 이동하며** 찍는다.
- 궤적(각각 골목 전체를 왕복한다):
  - V1: 가슴 높이(약 1.3m), 진행 방향 정면 → 되돌아올 때도 정면
  - V2: 머리 위 높이(약 2.2~2.5m, 셀카봉), 정면 → 3인칭 카메라 높이에 해당
  - V3: 중앙선에서 좌측 벽을 45°로, 되돌아올 때 우측 벽을 45°로
- 예상 분량: 약 **15~25분**

## 7. 스케일·위치 기준

- 줄자나 레이저로 **식별하기 쉬운 두 점 사이 거리 3곳**을 잰다. 예: 창틀 폭, 대문 폭, 맨홀 지름, 연석 간격.
  - 사진을 찍고 **메모장에 "사진 번호 + 측정값"**을 기록한다.
- 촬영 시작점과 끝점에서 폰 지도 앱의 **현재 위치를 스크린샷**한다.
- GPS 로거를 켜 둔다. 카메라 시계와 폰 시계를 1초 단위까지 맞춘다(촬영 전에 폰 화면의 시계를 카메라로 찍어 두면 된다).
- 표식을 바닥에 두거나 붙이지 않는다(공공 도로).

## 8. 촬영 예절·법적 주의 (05 문서 요약)

- **사람을 찍으려 하지 않는다.** 행인이 프레임에 들어오면 지나갈 때까지 기다린다. 우연히 찍힌 얼굴과 번호판은 파이프라인에서 블러·제거된다.
- 누가 촬영을 거부하거나 물어보면 **즉시 멈추고** 설명한다. 요청하면 해당 사진을 삭제한다.
- **창문 안쪽(가정집 내부)을 겨냥하지 않는다.** 유리 너머가 보이는 각도는 피한다.
- 사유지(대문 안, 주차장 안, 가게 안)에는 **들어가지 않는다.** 실내는 별도 동의 후 가이드 #2로 찍는다.
- 드론은 쓰지 않는다.
- 이 데이터는 **외부에 공유하지 않는다**(원본에는 얼굴과 번호판이 있다).

- 원본은 **외장 디스크 두 곳에 백업**한다. 클라우드에 올릴 경우 비공개 버킷에 둔다(D-007).

## 이 촬영으로 무엇을 만드나 (스파이크 1.0 연결)

| 경로 | 입력 | 처리 |
|---|---|---|
| (a) 메시 | 사진 P1~P4 | RealityScan → 고해상도 메시 + 8K 텍스처 → UE Nanite, Lumen |
| (b) splat → Cesium | 사진 + 영상 프레임 (RealityScan 포즈 공유) | Postshot(원본 해상도, SH3) → .ply → splat 3D Tiles(로컬 변환) → Cesium for Unreal |

| 공통 | (a)의 메시 | 충돌, 그림자 프록시, 정합 기준 |
