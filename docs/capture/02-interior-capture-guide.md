# 촬영 가이드 #2 — 실내 1곳 (MVP 1.5)

버전: v1 (2026-09-24) · 장비: **iPhone 17 Pro**(가이드 #1 §3·§4 설정 그대로)
전제: **서면 동의서에 서명을 받은 공간만** 찍는다(`docs/outreach/interior-consent-form-draft.md`).

## 0. 준비 (촬영 전날)
- [ ] 동의서 서명 완료. 촬영 범위(방·구역)를 사장님과 같이 확인한다.
- [ ] 시간: **영업 전이나 영업 후.** 손님·직원이 없어야 한다. 가게 기준 1~2시간을 잡는다.
- [ ] 치울 것: 서류, 영수증, 개인 사진, 켜진 모니터·POS 화면(끄거나 가린다), 흔들리는 물건(모빌, 커튼 끈).
- [ ] **조명**: 평소 영업 조명을 **전부 켜고 촬영 내내 그대로** 둔다. 조광기와 색이 바뀌는 조명은 고정한다.
- [ ] **창문**: 낮이면 바깥이 하얗게 날아간다. 블라인드를 반쯤 내리거나, **해가 진 뒤 촬영**하는 것을 고려한다(창 밖이 어두우면 실내 노출이 안정된다).
- [ ] 거울·큰 유리: 위치를 메모한다(나중에 충돌 blocker 처리). 가능하면 천이나 종이로 가린다.

## 1. 실내 특유의 주의점

| 문제 | 대책 |
|---|---|
| 실내는 어두워서 **셔터가 느려짐**(기본 카메라 앱이 1/60s 이하로 잡기 쉬움) | 한 장마다 **멈춰서** 찍는다. 셀카봉을 모노포드처럼 바닥에 짚는다. 첫 20장을 찍은 뒤 `golmok-exif`로 셔터를 확인한다. 1/125s보다 느린 컷이 많으면 조명을 추가로 켜고 알려준다. |
| 흰 벽, 무늬 없는 천장(특징점 부족) | 벽만 꽉 차게 찍지 않는다. **항상 가구·모서리·소품이 함께 보이게** 약간 물러서서 찍는다. |
| 창·유리·거울 | 정면으로 오래 겨누지 않는다. 비스듬한 각도로 1~2장만 찍는다. |
| 좁은 공간 | 초광각(0.5x)으로 바꾸고 싶어도 **1x 고정**. 대신 장수를 늘린다. |
| 혼합 조명(창빛 + 실내등) | 영상은 WB 고정(실내등 기준 약 3500~4000K). 사진은 기본 앱에 맡긴다. |

## 2. 사진 패스

방 하나(약 40~80㎡ 카페 홀)를 기준으로 한다.

### I1 — 벽 따라 바깥을 향해 (외곽 루프)
- 방 중앙 쪽에 서서 **반대편 벽을 향해** 찍으며 방을 한 바퀴 돈다.
- **0.5~0.7m마다**, 높이 3단(가슴 수평 / 아래 30° / 머리 위에서 위로 30°)으로 찍는다.
- 약 **250~350장**

### I2 — 벽에 붙어 안쪽을 향해 (내곽 루프)
- 벽에서 30~50cm 떨어져 **방 중앙을 향해** 찍으며 한 바퀴 돈다.
- 1m마다 가슴 높이 1장 + 사선 좌·우 각 1장씩 찍는다.
- 약 **120~180장**

### I3 — 가구·카운터·계단 궤도
- 카운터, 큰 테이블, 계단, 기둥 둘레를 반원 궤도로 15° 간격, 2단 높이로 찍는다.
- 약 **100~150장**

### I4 — 천장과 바닥
- 방을 격자로 걸으며 **천장 위 60°**와 **바닥 아래 60°**를 1.5m 간격으로 찍는다.
- 약 **80~120장**

### I5 — 문 통과 연결 (가장 중요)
- 이 패스가 **실외 골목 Zone과 실내 Zone을 이어준다.**
- 문을 연 상태로 **골목 쪽 3~4m 밖에서 시작해 문을 지나 실내 2~3m 안까지** 0.3~0.5m 간격으로 찍는다. 들어가면서 한 번, 나오면서 한 번 찍는다.
- 문틀, 문턱, 간판, 창을 **바깥과 안에서 모두** 담는다.
- 가능하면 **골목 촬영(가이드 #1)과 같은 날, 같은 날씨**에 찍는다.
- 약 **60~100장**

**사진 합계: 약 600~900장**(방 1개 기준). 방이 더 있으면 방마다 I1~I4를 반복하고, 방 사이 문마다 I5를 한다.

## 3. 영상 패스
- Blackmagic Camera 앱, 가이드 #1 §4-B 설정을 쓴다. 단 **셔터 1/125~1/250**, ISO는 필요한 만큼 올린다(실내).
- 궤적:
  - V1: 외곽 루프(가슴 높이, 벽을 향해)
  - V2: 머리 위 높이 루프(3인칭 카메라 시점)
  - V3: 골목 → 문 → 실내 → 문 → 골목 왕복
- 아주 천천히 걷는다. 약 **8~12분**.

## 4. 스케일·기록
- 줄자로 **문 폭, 카운터 길이, 바닥 타일 한 변** 3곳을 재고 사진 번호와 함께 `notes.md`에 적는다.
- 방마다 대략적인 평면 스케치를 그린다(손그림 사진이면 충분하다). 문과 창 위치, 거울·큰 유리 위치를 표시한다.
- 동의서 번호(`consent.record_id`)를 notes.md에 적는다. 서명본 자체는 저장소에 넣지 않는다.
